# Prompt pose RuangRealita

## Cara pakai
- Lampirkan gambar karakter (sheet lama) sebagai REFERENSI di setiap generate agar baju dan wajah konsisten.
- Satu prompt = satu baris berisi 6 pose (lebih stabil daripada 24 sekaligus). Satu karakter = 4 gambar.
- Simpan gambar dengan nama: `<Karakter>_baris1.png` ... `<Karakter>_baris4.png`, lalu kirim ke chat. Saya potong dan beri nama otomatis.
- Latar harus hijau polos #00FF00 agar mudah dipotong. Jika generator mengubah warna baju, generate ulang.
- Hasil disimpan di repo GitHub SAK362/RUANGREALITA, folder `sprites/poses/<Karakter>/`.

## Gaya (sama untuk semua prompt)
```
2D flat vector cartoon character, minimalist stickman-style: large perfectly round pure-white head, thick uniform black outline (about 6 px) around every shape, tiny solid black dot eyes, simple curved smile, no nose, no ears, no eyebrows. Soft flat colors with very subtle fabric texture, no gradients, no cast shadows, no 3D. Simple rounded limbs, small white round hands with no fingers drawn (except pointing index finger when requested). Full body head to toe, shoes included. Hands are ALWAYS EMPTY: no phone, cup, bag in hand, or any held object. Keep the exact same outfit, hair, colors and proportions as the attached reference character in every pose.
```

## Layout (sama untuk semua prompt)
```
Layout: character pose sheet, 6 poses in ONE horizontal row, evenly spaced, each pose fully inside its own invisible cell with generous margin, all feet on the same baseline, identical character height in every pose, solid flat pure green background (#00FF00), no text, no labels, no numbers, no grid lines, no shadows on the ground.
```
