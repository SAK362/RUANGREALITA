# Prompt lembar pose (untuk generator gambar)

Lampirkan lembar karakter asli sebagai referensi. Buat SATU lembar per pose (6 lembar). Setiap lembar harus memakai grid yang sama dengan lembar asli: 2 baris x 5 kolom, urutan Budi, Udin, Joko, Agus, Rizky / Siti, Dewi, Maya, Rina, Nina, latar putih polos, ukuran dan tata letak sama.

## Prompt dasar
Use the attached character sheet as the exact reference. Redraw the SAME 10 characters, same grid (2 rows x 5 columns), same order, same white background, same flat 2D style, same thick black outline, same clothes, colors and proportions, same blank white round head. Only change the pose: [POSE]. Keep the camera front-facing at the same scale, full upper body down to the same cut line. Do not add text, shadows, or backgrounds.

## Daftar [POSE]
1. TUNJUK: right arm (viewer's left) extended sideways and slightly up, index finger pointing, other arm relaxed.
2. JELASKAN: one hand raised to chest height, palm open, as if explaining, other arm relaxed.
3. PINGGANG: both hands on hips, chin slightly up.
4. SILANG: arms crossed over chest.
5. MENOLEH KIRI: head and body turned to three-quarter view facing viewer's left, arms relaxed.
6. MENOLEH KANAN: same, facing viewer's right.

Catatan: Maya tetap memegang ponsel, Joko dan Nina tetap memegang gelas dan tas jika pose memungkinkan; boleh dilepas untuk pose 1, 3, 4.
